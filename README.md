# Casa Quest 🏠

App familiar para gestionar tareas de la casa con gamificación.

## Usuarios
- Fede 🧔
- Cami 👩‍🦰

## Features
- Misiones con puntos y dificultad
- Boss semanal
- Ruleta de tareas
- Ranking semanal
- Sistema de recompensas canjeables

## Tech
HTML + CSS + JS vanilla. Persistencia via localStorage. Sin dependencias.

## Deploy
Cloudflare Pages — sitio estático.
